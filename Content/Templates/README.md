# Templates for Blender 5.0 for glTF-Exports

To use them, copy them to:
```
C:\Users\<User>\AppData\Roaming\Blender Foundation\Blender\<Version>\scripts\presets\operator\export_scene.gltf\
Library/Application Support/Blender/<Version>/scripts/presets/operator/export_scene.gltf/
~/.config/blender/<Version>/scripts/presets/operator/export_scene.gltf/
```
